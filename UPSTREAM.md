# Upstream provenance

HORIXON is a Rust port derived from the open-source Meteor Client project and the upstream `ShiraiFyuya/meteor-horizon` port. The imported engine and module source retain their original license notices and upstream attribution where applicable.


- Upstream port repository: https://github.com/ShiraiFyuya/meteor-horizon
- Upstream source license: GPL-3.0-or-later
- HORIXON's project license: GPL-3.0-or-later

HORIXON's package/build system is migrated to Horizon's flat native `.hmod` format and current `horizon-mod-api` SDK. This does not imply that every upstream module is fully implemented or runtime-tested.
